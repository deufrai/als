## Session

{{< als-ks >}}R{{< /als-ks >}} **starts** / **pauses** / **resumes** the session

{{< als-ks >}}X{{< /als-ks >}} **stops** the session

{{< als-ks >}}K{{< /als-ks >}} **acknowledges** issues

{{< als-ks >}}M{{< /als-ks >}} stacks in **mean** mode

{{< als-ks >}}S{{< /als-ks >}} stacks in **sum** mode
